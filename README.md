Stock Portfolio Tracker

Project Description:

Stock Portfolio Tracker is a simple Python-based project that calculates the total investment value of stocks. Users can enter stock names and quantities to calculate their investment.

Features:

1. Enter stock names.
2. Enter stock quantities.
3. Uses predefined stock prices.
4. Calculates total investment value.
5. Displays the investment summary.
6. Optionally saves the result in a text or CSV file.

Technologies Used:

- Python

Concepts Used:

1.Dictionary
2.User Input and Output
3.Basic Arithmetic
4.File Handling

How to Run:

1. Download the project.
2. Open the project in VS Code.
3. Run the Python file.
4. Enter stock names and quantities.
5. View the total investment value.

Example

Stock Prices:

AAPL = 180
TSLA = 250

Conclusion:

This project helps beginners understand Python dictionaries, user input, calculations, and file handling through a simple stock tracking application.
